# J.A.R.V.I.S. — помощник для Windows

Голосовой помощник в стиле Джарвиса из «Железного человека»: окно с «реактором», голосовые
команды на русском, управление компьютером, умный чат на Claude и поиск закупок по 44-ФЗ и
223-ФЗ с аналитикой.

## Что умеет

- **Закупки (ЕИС, zakupki.gov.ru).** Ищет текущие закупки по тегам (по умолчанию: проектор,
  мультимедиа, звуковое оборудование, оборудование для театра) по 44-ФЗ и 223-ФЗ. Показывает
  таблицу, сводку (количество, сумма и средняя НМЦК, деление по законам, крупные заказчики,
  закупки со сроком подачи 3 дня и меньше) и выгружает всё в Excel. Есть **мониторинг**:
  проверяет сайт каждые N минут и сообщает голосом о новых закупках.
- **Управление ПК.** Открывает программы и сайты, ищет в интернете, меняет громкость, ставит
  музыку на паузу, блокирует экран, выключает и перезагружает компьютер (с задержкой и отменой).
- **Умный чат (Claude).** Отвечает на любые вопросы и сам выбирает нужное действие, например
  «найди закупки проекторов дороже миллиона и скажи, у кого самый ранний срок».
- **Полезные мелочи.** Время и дата, погода, напоминания и таймеры, загрузка процессора и памяти.
- **Голос.** Кнопка «Говорить» или фоновый режим: скажите «Джарвис, …» и команду. Ответы
  озвучиваются голосом Windows.

Без ключа Claude помощник работает в простом режиме и понимает базовые команды: время, погоду,
«открой …», «громче», «напомни через …», «найди закупки …».

## Установка

1. Установите **Python 3.12** с сайта python.org. В установщике отметьте
   **Add python.exe to PATH**.
2. Скачайте папку `jarvis` (ветка `claude/zen-fermat-kmta52` вашего репозитория) на компьютер.
3. Дважды щёлкните **`run.bat`**. При первом запуске он создаст окружение и установит
   библиотеки, это займёт 2–3 минуты. Дальше `run.bat` запускает Джарвиса сразу.

Чтобы собрать отдельный `Jarvis.exe`, запустите `build_exe.bat` (после первого `run.bat`).
Готовая программа появится в `dist\Jarvis\`.

### Ключ Claude (для умного режима)

1. Получите API-ключ на console.anthropic.com (это платно, оплата по факту использования).
2. В Джарвисе откройте **Настройки**, вставьте ключ и нажмите **Сохранить ключ**.
   Ключ хранится в диспетчере учётных данных Windows, а не в файле.

Модель по умолчанию — Claude Opus 5.5. В настройках можно выбрать Sonnet 5.5 или Haiku 5.5:
они дешевле.

### Голос

- Распознавание речи идёт через сервис Google, нужен интернет.
- Голос ответа выбирается в **Настройки → Помощник**: нейросетевой «Дмитрий» (по умолчанию,
  бесплатно), ElevenLabs (студийное качество, нужен свой ключ с elevenlabs.io) или системный
  голос Windows. Если выбранный голос недоступен, Джарвис говорит запасным.
- Для озвучки нужен русский голос Windows: **Параметры → Время и язык → Речь → Добавить голоса →
  Русский**.

## Где что лежит

| Что | Где |
|---|---|
| Настройки | `%APPDATA%\Jarvis\config.json` |
| Журнал ошибок | `%APPDATA%\Jarvis\error.log` |
| Выгрузки в Excel | `Документы\Jarvis\` |

Свои программы добавляются в **Настройки → Программы** строками вида
`телеграм = C:\Users\Имя\AppData\Roaming\Telegram Desktop\Telegram.exe`.

## Проблемы

- **«ЕИС отклонила запрос (403)».** Сайт закупок часто не пускает зарубежные адреса. Отключите
  VPN.
- **«Не удалось проверить сертификат zakupki.gov.ru».** Сайт ЕИС использует сертификат Минцифры,
  которого нет в Python. Скачайте два сертификата с Госуслуг (страница gosuslugi.ru/crt) в папку
  `%APPDATA%\Jarvis\certs`:

  ```powershell
  $d = "$env:APPDATA\Jarvis\certs"; New-Item -ItemType Directory -Force $d | Out-Null
  Invoke-WebRequest "https://gu-st.ru/content/Other/doc/russian_trusted_root_ca.cer" -OutFile "$d\russian_trusted_root_ca.cer"
  Invoke-WebRequest "https://gu-st.ru/content/Other/doc/russian_trusted_sub_ca.cer" -OutFile "$d\russian_trusted_sub_ca.cer"
  ```

  Джарвис доверяет этим сертификатам только при запросах к ЕИС, настройки Windows не меняются.
  Можно также указать путь к своему файлу или папке в **Настройки → Закупки**. Если сертификат
  Минцифры уже установлен в Windows (например, Яндекс Браузером), всё работает и без этого.
- **Таблица закупок пустая, хотя на сайте закупки есть.** Возможно, ЕИС изменила вёрстку
  страницы. Разбор находится в `jarvis_app/procurement.py`, функции `parse_results` и
  `_parse_entry`.
- **Не ставится PyAudio.** Используйте Python 3.12: для него есть готовая сборка PyAudio.
- **Голос не распознаётся.** Проверьте, что микрофон выбран по умолчанию в настройках звука Windows.

## Для разработчика

```bash
pip install -r requirements-dev.txt
python -m pytest
```

Устройство:

- `main.py` — точка входа, окно на pywebview.
- `ui/` — интерфейс (HTML, CSS, JS).
- `jarvis_app/api.py` — мост между окном и Python.
- `jarvis_app/brain.py` — Claude с инструментами и простой режим без ключа.
- `jarvis_app/tools.py` — все действия помощника и их описания для Claude.
- `jarvis_app/procurement.py` — поиск, разбор, аналитика и выгрузка закупок.
- `jarvis_app/pc_control.py`, `utilities.py`, `voice.py`, `local_commands.py` — управление ПК,
  мелочи, голос и офлайн-команды.
